Mi Cita en Tiempo se apoya en datos y software abiertos. Gracias a sus autores.

## Datos de feriados

Los feriados de unos 200 países provienen del proyecto [date-holidays](https://github.com/commenthol/date-holidays) de commenthol y colaboradores. Los datos se publican bajo la licencia [Creative Commons Atribución 3.0](https://creativecommons.org/licenses/by/3.0/) y el código bajo la licencia ISC. Los usamos transformados a un formato propio.

## Tipografía e iconos

- Tipografía [Inter](https://rsms.me/inter/), de Rasmus Andersson, bajo la licencia SIL Open Font License 1.1.
- Iconos de [Lucide](https://lucide.dev), bajo la licencia ISC.

## Software

Construido con React, React Router, NestJS, Go, PostgreSQL, Better Auth, ALTCHA y otras bibliotecas de código abierto, cada una bajo su propia licencia.
